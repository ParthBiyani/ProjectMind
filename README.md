# ProjectMind

A cross-project engineering memory layer for coding agents.

Coding agents start every task with amnesia. They do not know you already solved
this problem in another repository, in another language, eight months ago. They
do not know which tools you tried and abandoned. Per-repository context files
cannot close that gap, because they are scoped to the repository they live in.

ProjectMind keeps two kinds of memory behind your agent and serves them over
MCP: a small, high-confidence **profile** of how you work, and a large
**episodic** record of what happened on which project and why.

Status: early development. See [docs/PRD.md](docs/PRD.md) for the full design
and [docs/roadmap.md](docs/roadmap.md) for what is built so far.
